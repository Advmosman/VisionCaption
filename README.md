# VisionCaption – Image Caption Generator

VisionCaption is a web application that generates captions for uploaded images. It allows users to upload an image and view a text description of its contents through a simple, user-friendly interface.

## Live Demo

https://visioncaption-8y9fj9t6m7nw8x2ucqn7to.streamlit.app/

## Features
- Upload images in JPG, JPEG, or PNG format.
- Generate captions automatically.
- View the uploaded image and its caption.
- Simple and easy-to-use interface.

## Technologies Used
- Python
- Streamlit
- PyTorch
- Hugging Face Transformers
- BLIP image captioning model

## Run Locally

**1. Clone the repository**
```bash
git clone https://github.com/Advmosman/VisionCaption.git
```

**2. Open the project folder**
```bash
cd VisionCaption
```

**3. Install the required packages**
```bash
pip install -r requirements.txt
```

**4. Run the application**
```bash
streamlit run main.py
```
